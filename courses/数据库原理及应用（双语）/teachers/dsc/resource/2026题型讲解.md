> 以下内容来自于老师最后一节课对题型的讲解

- 第一大题：E-R 图转换成逻辑图。就是生成几张表，每张表都要标出 primary key 和 alternative key。Alternative key 就是候选键减去 primary key。外键需要标出来。


- 第三题指出此状态下这张表是属于第几范式，为什么要给出解释。你需要证明为什么是符合此范式，与为什么不符合其他范式。

- 第 4 题是进行分解使表满足，直到满足 BCNF 范式，列出表当中关系的 primary key。第4题分解过程不需要叙述。


- 第五大题指出 Primary Key 和什么，然后指出表中所有的函数依赖是什么。

- 第六大题第一题是写一个查询，然后写出 SQL 语句与关系代数语句。第二题当中写 SQL 语句。Select 语句当中元素有单写算句 not exists 不考。最后一道题当中，题目给出了一定的限制，但不要忘记题目当中还有一定限制，比如 primary key。
