# 浙江财经大学计算机课程攻略共享计划

## 前言

本科教育的目的不在于取得何种学历或是技能，而在于为学生提供三到四年无所事事的时间。

无聊常常被人们视为一种应当避免的状态，以至于人们常常到短视频、游戏、课堂中去逃避它。但恰恰就是这样一种痛苦的状态，才使人能够反思自己的生活。

我从前总以为无聊是一种惩罚，在我长久的沉默中，焦虑和不安滋生。现在我觉得无聊是世界的沉默，生命一次次地发问，无论是以无聊、还是焦虑、或是不安的形式。它的问题很简单，你真的认可自己所做的吗？还是只将其当作对我诘问的逃避。

回答这个问题很容易，但找到自己真正认可的事业却很难。我不认为这样的事业是遗落在世界某处的宝藏等待着我的发现，它更像是一个模糊的概念，等待着我在无数次的尝试中逐渐将其变得清晰，最终创造出来。大学真正的价值就在于此，它应当给学生这样摸索的机会。

在这样一个信息极度充沛，ai高速发展的时代，传统的老师主导大班授课的教育模式已经不适应于这个时代了。我们应当把学生们从传统的课堂中解放出来，把生活还给生命。如果能有一个学生因为这个项目而有了更多无所事事的时间，那就算是对我莫大的安慰了。

### 操作方法

推荐采用在 **GitHub Web 端直接上传** 的方式，具体操作如下：

1. 首先 Fork 本项目

2. - 上传文件到已有文件夹：打开对应文件夹，点击绿色 Download 按钮旁的 upload，上传你的文件。

   - 上传文件到新文件夹：打开任意文件夹，点击绿色 Download 按钮旁的 upload，**把浏览器地址栏中文件夹名称改为你想要新建的文件夹名称，然后回车**，上传你的文件。

3. - 提交 PR

或者也可以直接附加在 **Issue** 中，由维护者进行添加。

或者也可以发送邮件至 **zzzoutzzz@protonmail.com** ，由维护者进行添加。
